# V4.1 synthetic examples

These files are actual outputs of the Design Pack/prompt/compositing/typography
builders, using synthetic labelled rectangles and an ellipse mask. No real
video, person, Hearthstone artwork, ASR or image model is involved.

- `precision_preservation_preview.png`: four 160×90 local previews in a 2×2 grid.
- `design_pack_C1.json`: the actual serializable protected card example.
- `generation_prompt_C1.txt`: environment-only prompt from `pack_prompt`.
- `preflight_and_typography.json`: actual portfolio corrections, font resolution,
  treatment metadata and technical text warnings.

The identical accented hook is intentional, to compare the four treatments.
The labelled coloured shapes are stand-ins, not invented official cards/faces.
Source files and 1920×1080 local finals were rendered in the ignored `build/work/`
validation directory. The JSON's source names/IDs are synthetic examples.
This is not an AI-generated artistic comparison or a prediction of YouTube quality.
